# Comtable Web

The **Comtable Web** repository is the frontend of [Comtable Api backend](https://github.com/chawkitariq/comtable-api). It provides a web application interface for managing accounting business.

## Setup

Environment Variables:

- Copy the `.env.example` file to `.env` to configure your environment variables.

## Development

```bash
# Start app
docker compose up

# Stop app
docker compose down
```
